# Privacy Policy for Kuroko Bots

**Last Updated:** July 2026

## 1. Introduction

This Privacy Policy explains how Kuroko Bots ("the Bot", "we", "our", or "us") collect, use, store, and protect information while providing services through Discord.

By inviting or using any Kuroko Bot, you agree to the practices described in this Privacy Policy.

---

## 2. Information We Collect

Depending on the features used, the Bot may collect and process:

* Discord User IDs
* Discord Server (Guild) IDs
* Discord Channel IDs
* Discord Role IDs
* Discord Message IDs
* Voice Channel IDs
* Server configuration settings
* Moderation records (warnings, jail records, verification data, bans)
* Music queues and playback settings
* Voice activity statistics
* Verification and security logs
* Whitelist and blacklist configurations

The Bot does **not** collect passwords, payment information, or private Discord account credentials.

---

## 3. Message Content

The Bot may temporarily process message content only when required to:

* Execute prefix commands.
* Detect prohibited links.
* Detect Discord token leaks.
* Perform moderation and security actions.
* Execute server management features.

Message content is **not** permanently stored unless required for features explicitly enabled by server administrators (such as moderation logs or snipe functionality).

---

## 4. Presence Information

If enabled, the Bot may access Discord Presence information to provide moderation, voice management, and server management features.

Presence information is only processed for bot functionality and is never sold or shared.

---

## 5. How We Use Data

Collected information is used only to:

* Provide bot features.
* Manage server configuration.
* Execute moderation actions.
* Protect servers against abuse.
* Improve stability and performance.
* Generate statistics requested by server administrators.

---

## 6. Data Storage

Only the minimum amount of data necessary for the Bot to function is stored.

Stored data may include:

* Configuration
* User IDs
* Role IDs
* Warning history
* Verification records
* Music preferences
* Voice statistics

---

## 7. Data Sharing

We do **not** sell, rent, trade, or share user data with third parties.

Data may only be disclosed when required by law.

---

## 8. AI & Machine Learning

Kuroko Bots do **not** use Discord message content, user data, or server data to train artificial intelligence or machine learning models.

---

## 9. Data Security

Reasonable technical and organizational measures are used to protect stored information against unauthorized access, disclosure, alteration, or destruction.

---

## 10. Data Removal

Server owners may request deletion of stored server data by contacting the developer through the official support server.

Some data may also be automatically removed when the bot leaves a server.

---

## 11. Third-Party Services

Kuroko Bots may interact with Discord APIs and supported music providers where applicable.

Use of those services is governed by their respective privacy policies.

---

## 12. Children's Privacy

The Bot is intended only for users who comply with Discord's Terms of Service.

---

## 13. Changes

This Privacy Policy may be updated at any time.

The latest version will always be available through the official Privacy Policy link.
